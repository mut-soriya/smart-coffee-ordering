# Smart Coffee — REAL PHOTO PACK

This package is intentionally NOT filled with generated placeholder images.

It contains:
- 50 unique real-photo Pexels sources
- A Windows downloader that downloads the actual JPG files
- Product filenames that match the 50-product dataset
- `js/products.js`
- `sources.txt` with the Pexels source page for every photo

## How to get the actual 50 JPG files

1. Extract this ZIP.
2. Double-click `DOWNLOAD-REAL-PHOTOS.bat`.
3. Wait until it says DONE.
4. Your real photos will be inside:
   `assets\coffee\`

Then copy that `assets\coffee` folder into your Smart Coffee project.

## Why the JPGs aren't already inside this ZIP

The ChatGPT file environment used for this response cannot reliably fetch external image bytes from Pexels into a ZIP. I therefore did NOT substitute fake/generated pictures again.

The included downloader uses the real Pexels image URLs and downloads the actual photos directly on your Windows PC.
